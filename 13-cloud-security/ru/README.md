# Облачная безопасность

## Модели и общее
- **IaaS / PaaS / SaaS** — инфраструктура / платформа / готовый сервис.
- **Shared Responsibility** — провайдер отвечает за облако, ты — за конфигурацию в облаке.
- Главная причина утечек — **misconfiguration** (открытые S3, слабый IAM, exposed порты).

## AWS — ключевое
- **IAM** — пользователи/роли/политики. Риски: чрезмерные права, старые ключи, root без MFA.
- **S3** — хранилище. Риск: публичные бакеты (утечки данных).
- **EC2** — виртуалки. Риск: открытые Security Groups (SSH/RDP в интернет), метадата-сервис (SSRF → креды).
- **Security Groups** — файрвол уровня инстанса.

## Инструменты аудита облака
| Инструмент | Что делает |
|---|---|
| **AWS Trusted Advisor** | встроенный AWS: рекомендации по безопасности/стоимости/производительности |
| **Scout Suite** | мульти-облачный аудит конфигурации (AWS/Azure/GCP), HTML-отчёт |
| **Prowler** | AWS security scanner по CIS Benchmark / compliance (сотни проверок) |

```bash
# Prowler
prowler aws                        # полный аудит AWS по CIS
# Scout Suite
scout aws                          # аудит → HTML-отчёт
```

## Что проверять (чеклист)
- IAM: MFA у всех, нет root-ключей, принцип наименьших привилегий, ротация ключей.
- S3: нет публичных бакетов, шифрование включено.
- Сеть: Security Groups не открыты в `0.0.0.0/0` на чувствительные порты.
- Логирование: CloudTrail включён, мониторинг аномалий.
- Шифрование: at-rest и in-transit.

## Прочее облако
- **Azure** — аналог AWS (AD → Entra ID, важно для корпоративных атак).
- **GCP** — Google Cloud.
- **Kubernetes** — см. `06-servers-and-services` (контейнеры).
- **DevSecOps** — безопасность в CI/CD (yaml-пайплайны, сканирование образов, secrets management).
